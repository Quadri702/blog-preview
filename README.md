# Blog Preview

A simple responsive blog preview card built with HTML and CSS.

## Features

* Responsive design
* Blog preview card
* Clean and simple layout
* Mobile and desktop layouts

## Tech Stack

* HTML
* CSS

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Quadri702/blog-preview.git
cd blog-preview
```

### Run the project

Open the `index.html` file in your browser.
